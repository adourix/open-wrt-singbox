# Routing

Generated by `core/config/generator.sh` for sing-box 1.13.21.

```text
LAN client -> br-lan / fw4 -> sing-box TUN (tun0, 172.19.0.1/30) -> proxy-out -> Internet
```

- TUN inbound: `auto_route`, `auto_redirect`, `strict_route` all enabled. With
  `auto_redirect` the main default route is unchanged; marked traffic uses
  policy routing (table 2022) and sing-box's own `inet sing-box` nftables table.
- `route.auto_detect_interface: true` keeps sing-box's own connection to the
  proxy server off the TUN (no loop).
- Rules, in order:
  1. `1.1.1.1/32`, `8.8.8.8/32` → `direct` (resolvers for the proxy endpoint)
  2. private addresses (`ip_is_private`) → `direct` (LAN, router management)
  3. port 53 TCP/UDP → `hijack-dns`
  4. everything else → `proxy-out`
- IPv6: the MVP is IPv4-only. `core/network/firewall.sh` owns the nftables table
  `inet singbox`, which drops forwarded IPv6 from `br-lan` so it cannot bypass
  the proxy. The table is created on start and deleted on stop/recovery.

Do not replace the main default route by hand, and do not edit fw4's tables.
